# Question history

In **Question library**, use **Question history** to view all questions, questions recorded in saved games, or questions with no recorded use. Category, text search and review filters still apply together.

Each card shows the number of matching saved games. Open a question, then expand **Saved game history** to open those games in a separate tab.

Regular-round history includes boards opened in saved games, even if the host has not finished that board. Fast Money history includes questions with at least one recorded response, including zero-point responses. Selecting a Fast Money pack alone does not count as use. Two players answering the same question count as one game.

The two libraries have separate counts. Rehearsals are excluded. Deleting a game removes its contribution, and undo follows the saved game state. There is no permanent independent tracking log. “Not recorded” therefore does not mean “never played.” A spoken question without a saved Fast Money response cannot be inferred from these records.

Matching follows the library's normalised prompt text, not pack IDs, so copies of the same wording share counts within their round type. These filters do not automatically exclude questions when creating a game. Refresh the library after another host changes or deletes games.
