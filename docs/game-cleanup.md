# Managing saved games

On the host desk, scroll to **Your games**. The **Show games** selector offers:

- All games: every saved game.
- Live games: unfinished games, excluding rehearsals. This describes game state, not whether players are currently online.
- Ended games: finished games, including ended rehearsals.
- Rehearsals: practice games, whether active or ended.

Open a card to resume a game or view its results. **End game** stops the game and keeps saved scores; unfinished round points are not awarded. **Delete** permanently removes that individual game after confirmation.

For cleanup, select checkboxes on ended games, or use **Select visible ended games**. Only the cards currently shown are selected. **Show all** expands the current filtered view. Switching filters clears selection.

**Delete selected ended games** lists the game codes and team names for confirmation. Cancellation changes nothing. Deletion removes scores, history and phone registrations; it cannot be undone. Download any scorecards you want to retain first.

The server checks each selected game's revision and ended state. If another host changes or resumes a game, that deletion fails rather than removing an active game. Cleanup proceeds per game and reports successes and failures; it is not an all-or-nothing transaction. The list refreshes afterward.

No existing production games are deleted by deploying this feature. Hosts choose which games to remove.
