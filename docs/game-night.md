# Game-night quick check

Use https://ff.adeticket.com. Checked against release 83626ca on 11 October 2026.

## Before guests arrive

1. Sign in to the host desk. Open the intended saved game, or create one with the correct teams and question pack. Check the question-mix preview and any question-use limit before creating it.
2. Use a separate Practice game for a quick round and Fast Money rehearsal. Practice does not add question usage. Do not practise by revealing answers in tonight's real game.
3. Open Audience screen and put its public board on the actual TV/display. Check readable text, picture and volume. Use the audience sound test; a connected screen alone does not prove sound works.
4. Expand Event readiness. Confirm picture and audible sound (or intentionally silent mode). On two real phones, join, approve and stage a player for each team; open buzzers and confirm the host sees the winner. Return to the intended starting stage.
5. Keep the host device powered and on reliable Wi-Fi. Keep the host URL private; share the player join link/QR with guests. Lock new joins once everyone needed has joined.

## During play

- Use Pause for interruptions. Review the board before using Undo.
- In Fast Money, board selections or Record & next save answers. Typed drafts alone do not score and clear on reload. End turn & reveal asks for confirmation; cancelling does not pause the timer.
- On a timeout or reconnect, check the latest board/state before repeating an action. A timed-out request may already have applied. Commands are not automatically retried.
- If casting fails, use the public Audience link on a browser/display or a cable connection. Real TV discovery and audio must be checked on your hardware.

## After play

Download the completed scorecard if wanted. Keep saved real games if using the question-use limit: deleting game history can make its questions eligible again. Delete only unwanted Practice games after reviewing the confirmation.

No production restart, saved-game deletion or owner-data edits were performed for this housekeeping pass. Hardware sound/casting and production restart durability remain unverified.
