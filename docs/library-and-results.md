# Question review and scorecards

The question library flags identical prompts after case, punctuation and spacing
normalization, and accepted variations shared by different answers. Use **Show
questions needing review** to filter the selected pack. Review warnings also appear
in the editor and import preview. Warnings do not block saving: the host may choose
to clarify overlapping meanings in the notes. Semantic similarity is not inferred.

Question cards count saved non-rehearsal games that have opened the board. Future
queued questions do not count. Counts match normalized prompt text across packs;
deleting a game removes its contribution. Counts refresh when the library opens.

The host's **Game-night results** appears when the champion is selected or a game
ends. **Download scorecard** saves a spreadsheet-compatible CSV containing the game
ID, team totals, declared champion, recorded round awards, and completed Fast Money
answers and points. Incomplete Fast Money answers are not exported.

Round awards are recorded from this release onward and follow Undo. Older totals
are preserved; an incomplete breakdown is labelled instead of reconstructing past
awards. Fast Money rehearsal starting scores are likewise not real recorded rounds.

Backups and restore are not included. End or delete older games from the host desk.
